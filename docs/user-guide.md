# 三际观用户指南

## 从哪里开始

首次进入先建立主体并如实填写资料。出生时刻不知道时请选择“未知”，系统不会用中午、午夜或随机时辰补齐。保存后，可从“记录”写下愿向、梦境标签、行为、人生事件、关系事件或实物三钱结果，再到“合参”选择工具。

## 怎样读结果

- **象势**：现有证契指向该象的力度。
- **证契完备度**：资料是否完整、独立、稳定且少冲突。
- **证契 / 逆证**：支持判断与反向约束判断的资料。
- **相争**：主要候选接近或冲突明显，应同时阅读双方依据。
- **不成断**：资料不足，系统不会为了给答案而强行下结论。
- **【可能】**：规则推演字段，不是用户直接记录的历史事实。

技术版本、Hash、Replay 参数位于“研究详情”。“按原版本重放”使用当时的输入和规则；“用当前版本重新分析”会新建结果，不覆盖历史。

## 网络或服务失败

页面会保留尚未提交的输入。先检查本机服务，再点击重试；错误中的“关联 ID”可用于查日志，但不要把出生资料、梦境或关系正文粘贴到公开问题中。离线页只保存公开壳层，不缓存私人记录。

## AI 成文

没有 DeepSeek 密钥时仍能生成完整确定性报告。启用成文服务后，它只能润色已经确定的象辞和释义，不能改变姓名、排盘、分数、排名、吉凶、应期、证契、逆证或 Hash。

## 删除与导出

导出只由用户主动触发。删除与撤销含义不同：撤销资料不参与新执行；彻底删除可能使历史 Replay 无法完整重现，系统会明确显示 `replay_unavailable`，不会伪造恢复。
