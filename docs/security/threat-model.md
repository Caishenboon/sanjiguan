# 威胁模型与安全基线

## 核心资产

出生与地点、梦境/修行/关系日志、关系同意、分析快照、规则与知识来源、会话、加密密钥和 DeepSeek 密钥。

## 主要威胁与控制

- 密钥泄漏：Secret Manager 注入；后端专用变量；日志/追踪 scrub；出站 allowlist；90 天轮换；CI secret scanning。
- 越权读取：HttpOnly + Secure + SameSite=Strict 会话；PostgreSQL RLS；对象级授权；viewer 显式授权与撤销。
- 提示注入：用户文本永不进入 system 指令；RAG 仅已审核片段；结构化 schema；模型不能写计算字段。
- 敏感数据外发：模型输入最小化，移除姓名、精确地址、邮箱；记录 chunk ID 而非原文日志。
- 规则供应链篡改：规则 checksum、版本状态机、双人审批、激活审计、不可静默覆盖。
- 重放与重复扣费：所有写操作要求 Idempotency-Key；请求指纹、响应缓存和冲突检测。
- 删除不完整：删除编排覆盖主库、pgvector、Redis、对象存储和队列；保留匿名审计；记录备份消除上限。
- 依赖/镜像风险：锁文件、依赖审计、镜像扫描、最小化运行用户和只读文件系统（部署阶段）。

## 人工阻断项

- 必须在 DeepSeek 控制台吊销此前暴露的旧密钥。仓库无法验证或代为吊销。
- 新密钥不得通过聊天传递；仅由部署平台 Secret Manager 或本地忽略文件配置。
