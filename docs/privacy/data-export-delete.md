# 数据导出、撤销与删除

用户可主动请求导出。服务生成带 Manifest、Schema 版本、文件 Hash、版本引用和
缺失说明的 ZIP，下载窗口最长 15 分钟，导出记录最长保留 24 小时并可立即撤销。
导出不包含密码、Session、数据库凭据、字段加密密钥或其他用户资料。

系统区分：

- 撤销：新执行不再使用，历史快照仍可按当时版本 Replay；
- 软删除：普通列表隐藏，按政策保留最小恢复/审计状态；
- 彻底删除：删除私人正文和快照，相关 Replay 明确不可用；
- 账号删除：清除主体及私人派生数据，不删除公共规则和共享研究资产。

离线备份按保留周期自然过期，不能承诺即时修改已离线保存的旧备份。日志、缓存和
临时导出不得继续保留私人正文。
