# Sprint 1B-1：三际录与六象证据采集

## 已实现

- 八步立卷、断点续填的数据契约与界面。
- 梦象、感应象、业象、愿象、缘象、世象及人生事件的加密证据底座。
- 记录可靠性、资料完整度和时间线；两者均不构成术数或宿世评分。
- 修行日志与证据关联。
- 关系对象的同意、撤回与匿名事件模式。
- 实物三钱六次结果录入，可回放原始币面；不生成卦义和评分。
- 所有新增资料表启用并强制 RLS；写接口遵循 24 小时幂等契约。

## 安全边界

敏感叙述、结构化字段、标题、问题和用途在应用层加密后入库。匿名事件拒绝姓名、
电话、邮箱、社交账号、精确地址和证件字段。日志不得输出明文资料。

## 明确未实现

八字、紫微、自动宿世本卦、宿世身份评分、中阴评分、高修行或大愿型、名人匹配、
K 线、DeepSeek、Embedding、RAG 与任何自动术数解释均保持关闭。

## 验收方法

运行 Python 单元/API/PostgreSQL 测试、重复迁移与漂移检测、OpenAPI/JSON Schema
同步、Web 生产构建、Secret Scan、产品语言门禁和 `validate_sprint1b1.py`。
