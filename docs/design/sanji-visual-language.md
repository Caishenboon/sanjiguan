# 三际观视觉语言 1.0

## 品牌与信息原则

关键词：克制、深静、可追溯、古意而不仿古、研究而不后台化。
产品原则是“大屏观三际，小屏录一念”。版本、规则状态、研究警告与
哈希属于一等信息，不得为视觉整洁而隐藏。

## Tokens

- 基础：墨黑 `#080b12`、青黛 `#17243a`。
- 正文：月白 `#f2efe7`；次级正文 `#c7c5bd`。
- 主象：雾金 `#c7ad72`，不得铺满整屏。
- 宿世研究：幽紫 `#9178c6`。
- 愿力与支持证据：玉青 `#63b7a5`。
- 逆证、风险与冲突：暗红 `#9c4f55`，不得装饰性滥用。
- 字体：标题、象辞、断章使用锁定的 Noto Serif SC；正文与表单使用
  Noto Sans SC；Hash、版本、Trace 使用 Noto Sans Mono。三个字体通过
  Fontsource `5.3.0` 构建依赖取得，均登记为 `OFL-1.1`；仓库不直接
  提交字体二进制。视觉测试不得依赖系统字体 fallback。
- 字号：正文 16px；说明 12–14px；页面标题 `clamp(40px,7vw,91px)`。
- 内容栅格：最大 1180px，12 栏；8/4、4/4/4 与整栏组合。
- 间距：4px 基数；组件主要间距 8/12/16/24/40/56。
- 圆角：8/16/28px；边框为低对比单线。
- 阴影：只用于区分信息层，不模拟廉价悬浮卡片。
- 光晕：仅允许页面背景一个低饱和幽紫光域。
- 动画：120–240ms；只表达层级变化，不持续漂浮。减少动画模式将
  所有非必要动画降至近零。
- 图标：Lucide 线性图标，必须与文字标签并用；不可用图标替代规则状态。

## 响应式与主题

- 桌面 ≥ 1024px：完整研究图谱与多栏证据。
- 平板 768–1023px：保留宫格和并列摘要。
- 手机 < 768px：优先录入、摘要和研究警告；<520px 导航折叠。
- 深色是研究工作台默认；浅色跟随系统偏好，保持相同语义色。
- 所有交互支持键盘焦点、屏幕阅读器名称和至少 AA 对比度。
- 卦象和星盘必须提供文本替代；不可只用颜色表达吉凶或状态。

## 禁止模式

禁止满屏金色、廉价粒子、遍地发光边框、不可读小字、每页独立视觉
语言、通用后台模板、装饰性“宇宙/灵魂”堆砌、用动画掩盖加载状态。
