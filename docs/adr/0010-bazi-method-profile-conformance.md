# ADR-0010：八字方法档案与验证基座

- 状态：Accepted for research foundation
- 日期：2026-07-27

## 背景

D-001 只冻结时间资料与双轨敏感性，D-002/D-003 仍有流派和来源缺口。直接实现四柱
会把工程假设冒充为传统规则，也会使历史回放无法解释。

## 决定

1. 在 `sanji-engine/bazi` 内建立版本化 Method Profile、Evidence Bundle 和 Boundary Cases。
2. 候选 Profile 可显式选择不同政策，用于验证差异；全部不可生产激活。
3. Conformance Harness 只验证结构、引用、哈希和政策差异。
4. Engine 请求八字模块时必须指定 Profile；请求合法后仍返回 `MODULE_DISABLED`。
5. 74 个案例全部为合成研究数据，不称为权威八字金样例。
6. Owner 工作台只显示分歧、来源和案例，并复用 Claim 工坊记录审校意见。

## 结果

优点是方法分歧可审计、可跨平台复现，且不会产生临时算法。代价是正式四柱仍被
阻断，并需要合格八字审校人、来源定位和签字案例才能进入后续实现 Sprint。

## 不在本决定内

年/月/日/时柱算法、十神、旺衰、起运、大运、流年、吉凶及任何映射。
