# ADR-0003：规则集激活门禁

- 状态：Accepted
- 日期：2026-07-23

## 决策

八字、紫微、易经规则包初始均为 `draft`，`method_id` 使用显式的 `UNCONFIRMED` 占位，运行时 feature flag 默认关闭。激活必须同时满足：

1. 产品负责人确认流派、公式、边界规则和权威金样例；
2. 规则来源、版本、checksum 完整；
3. JSON Schema 与金样例测试通过；
4. 两人复核并产生审计事件；
5. 不存在 `UNCONFIRMED` 或未审核知识引用。

管理 API 不得绕过门禁。激活是显式状态迁移，不得随部署自动发生。
