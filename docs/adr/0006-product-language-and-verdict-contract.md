# ADR-0006：三际观术语与结构化断语边界

- 状态：Accepted
- 日期：2026-07-23

## 决策

用户可见品牌冻结为“三际观”，引擎为“三际枢”，长期档案为“三际录”，综合过程
为“六象合参”，最终报告为“三际断章”。内部工程标识继续使用
`samsara-engine`，不破坏数据库表、API 或目录。

核心断语采用版本化 JSON Schema。规则引擎拥有判断骨架、极性、强度、排序、
状态、应期、证据和吉凶主导方向；未来 LLM 只能组织象辞、释义及段落，不得改写
锁定字段。系统自创象辞不得伪装成经典引文。

## 后果

品牌和报告字段由 CI 静态检查。Schema 阈值只是结构设计，不构成已激活的评分规则。
“三际观”不得被宣传为经典已有宗派或法门。
