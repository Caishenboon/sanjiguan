# 产品负责人决策边界

下列事项没有因工程 RC 完成而自动获批，新 Agent 不得代替负责人决定：

| 事项 | 当前状态 | 未经确认不得做 |
|---|---|---|
| 代码许可证 | AGPL 候选 | 写入正式许可或公开发布 |
| 规则与知识资产许可证 | CC BY-SA 候选，需分层治理 | 假定代码许可覆盖规则/知识 |
| 商标政策 | 未定 | 授权品牌复用 |
| Restricted/Sealed 内容 | 禁止摄入、嵌入、操作性转述 | 以“研究”名义绕过限制 |
| VedAstro | 固定研究来源、再分发待审 | 公开完整数据或当作独立真值 |
| DreamBank | 许可复核未闭环、Connector 禁用 | 下载或提交正文 |
| 公共人物与敏感推断 | 需隐私与法律审查 | 制作在世人物敏感预测 |
| 生产 KMS | 未选型 | 用开发密钥替代生产方案 |
| 数据地区 | 未冻结 | 承诺地区或跨境路径 |
| 备份保留、删除 SLA | 未冻结 | 宣称离线备份可即时删除 |
| 生产规则激活 | 全部未激活 | 将研究态升级为生产共识 |
| 仓库 Public、Tag、Release | 未授权 | 自动公开、打 Tag 或发布 |

传统/传承审校人必须具有相应资格；Codex、LLM 或普通工程审核者不能替代。
