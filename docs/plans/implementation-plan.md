# 分阶段实施与验收计划

## Sprint 0：决策与安全基线（本轮）

交付 ADR、目录、Schema、迁移/API 草案、安全配置、10 个输入金样例和自动基线检查。验收：同一 canonical JSON 产生相同 SHA-256；三术 feature flag 默认关闭；仓库扫描无密钥；规则清单均为 draft；契约和迁移可静态校验。

条件：因 D-001 至 D-007 未确认，Sprint 0 的“规则方法冻结”验收暂不成立，其余工程基线可完成。

## Sprint 1：档案与确定性计算（2 周）

实现邀请制认证、档案/证据、加密、时间地点规范化，以及已确认方法的八字和基础易经。未知时辰并行 12 候选。验收：经负责人签字的边界金样例逐字段一致；闰月/节气/时区属性测试；无伪造时柱；RLS 越权测试。

## Sprint 2：规则与候选竞争（2 周）

实现有来源的业愿/中阴规则、60 个平衡原型、统一信号、反证、三重印证和审计回放。验收：规则单测覆盖率不低于 90%；相同输入/规则/种子字节级稳定；缺失数据只降低置信；高修行开关默认关闭；名人先验惩罚测试。

## Sprint 3：RAG 与 DeepSeek（2 周）

实现知识摄入审核、混合检索、后端 Gateway、结构化输出与规则模板回退。验收：前端 bundle/网络/日志无密钥；提示注入与 100 条 LLM 固定评测；零伪造引用；DeepSeek 故障时规则分析仍可用；成本幂等。

## Sprint 4：K 线与二维轮回地图（2 周）

实现五维信号、三轨条件模拟、置信带、SVG/Canvas 数据驱动地图。验收：每个点可追溯到 driver；OHLC 不变量；假设只影响允许矩阵；移动端与键盘可用；WCAG 2.2 AA 检查。

## Sprint 5：关系、日志、版本与交付（2 周）

实现同意/匿名关系模式、日志趋势、版本对比、导出/删除、监控与恢复。验收：完整 E2E；主库/向量/缓存/对象/队列删除闭环；季度恢复演练脚本；OWASP ASVS L2 关键项；p95 性能预算。

## 发布门禁

每阶段均要求：版本化契约与迁移、单元/集成/E2E/安全测试、回滚方案、审计证据、文档同步。未确认流派的模块不得以“测试通过”为由激活。
