# 知识库公开边界

| 来源类别 | V1 RC 公开处理 | 原因 |
|---|---|---|
| BDRC | Locator/书目信息；逐项待确认 | 可访问不等于可再分发扫描或全文 |
| 84000 | 可链接和少量合规引用；译文全文不摄入 | 译文与网站内容保留其权利声明 |
| FPMT | 可链接和登记书目；修法正文不摄入 | 授权、传承与修法资格需逐项核验 |
| 古籍扫描 | 仅元数据/Locator，除非文件权利明确 | 扫描版可能有数字化与馆藏权利 |
| 现代译文和注疏 | 可引用但不可默认再分发 | 现代文字通常受版权保护 |
| 现代命理资料 | 规则来源登记；不复制大段正文或表格 | 工程实现与文字版权分开治理 |
| 用户提供资料 | Private/Restricted，不得进入公开仓库 | 隐私、同意与用途限制 |
| 自动抓取内容 | 默认禁止 | 来源、许可与完整性不可自动推定 |
| 灌顶、口传、sealed 内容 | Sealed；不得摄入、嵌入或转述步骤 | 传承与访问边界不可绕过 |

跨传承内容只允许并列参照并保留标签，不得无标签融合成虚构的统一密宗体系。
传统陈述、三际观二次映射与工程假设必须分别标注。
