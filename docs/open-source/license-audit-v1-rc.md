# V1 RC 许可证审计

## 结论

仓库继续保持 Private，尚未获得公开授权。已准备但未激活的候选方案为：原创代码
AGPL-3.0-or-later；原创规则数据、方法文档与非软件知识结构 CC BY-SA 4.0；第三方
资产保留原许可证。根 `LICENSE` 明确说明当前不授予许可，避免在负责人书面批准前
作出不可逆授权。

## 第三方边界

机器清单以 `third-party-lock.json` 和 `sbom.cdx.json` 为准，人工摘要以
`THIRD_PARTY_NOTICES.md` 为准。MIT、BSD-3-Clause、Apache-2.0、ISC、OFL-1.1
与 PostgreSQL License 项目必须在公开前再次核对完整版权声明和传递义务。固定的
`liuyao-engine` 选定文件快照必须保留 Apache-2.0 LICENSE/NOTICE。

现代解释文字、视觉资产及来源不明数据不随上游软件许可证自动获得再分发权。
VedAstro 数据仍为外部研究未核验层；DreamBank Connector 保持禁用且不得提交正文。

## 负责人仍须确认

1. 是否正式激活 AGPL-3.0-or-later；
2. CC BY-SA 4.0 的适用目录与规则资产边界；
3. 商标与品牌使用政策；
4. Fixture、截图与文档中第三方内容的逐项许可；
5. 在完成全历史安全扫描和知识内容复核后是否批准公开。
