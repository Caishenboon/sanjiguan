# 开源准备状态

当前 GitHub 仓库必须保持 **Private**。存在许可证文件也不构成公开授权；本阶段
不选择许可证、不改变可见性。公开前必须由产品负责人逐项书面批准：

- [ ] 对 Git 全历史执行 Secret Scan，并处理所有历史泄露。
- [ ] 删除个人资料、出生资料、关系资料、梦境、修行日志及测试敏感数据。
- [ ] 复核密宗资料的公开、灌顶、口传和 restricted/sealed 边界。
- [ ] 复核知识库全文、译本、图片及注疏的版权与摄入授权。
- [ ] 生成并审核全部第三方依赖许可证清单。
- [ ] 由产品负责人选择开源许可证。
- [ ] 完成面向外部使用者的 README。
- [ ] 完成 SECURITY.md 和漏洞报告渠道。
- [ ] 完成 CONTRIBUTING.md、行为规范和贡献者来源声明。
- [ ] 完成隐私政策、数据地区、备份、删除与导出说明。
- [ ] 人工确认所有 Demo/fixture 完全虚构且不可关联真实个人。
- [ ] 确认所有 GitHub Actions job 使用最小权限。
- [ ] 确认 DeepSeek 仅由后端环境变量 `DEEPSEEK_API_KEY` 注入。
- [ ] 产品负责人书面批准将仓库改为 Public。

任何一项未完成时不得公开仓库。
