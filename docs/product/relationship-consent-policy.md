# 关系同意与撤回策略

同意状态为 `pending`、`granted`、`withdrawn`、`expired` 或
`anonymous_event_mode`，并记录版本、同意/撤回/到期时间、证明类型、scope 和
创建人。同意与 viewer 授权相互独立。

- 只有 `granted` 且未到期的记录可用于创建新的双人分析。
- 撤回后立即禁止新的双人分析；已有报告保留为历史审计对象，但默认不再展示，
  后续删除须遵循尚未冻结的 D-010。
- 匿名事件模式只能保存去标识化事件描述，不得保存对方姓名、联系方式、
  精确生日、账户 ID 或其他可识别资料。
- 本阶段只落实数据、权限和状态契约，不生成因缘关系评分。
