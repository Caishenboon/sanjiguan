# 三际观 V1 用户语言与术语规范

三际观是产品，三际枢是确定性核心，三际录是个人档案。六象是三际观原创研究体系，所有相关结果继续标记为研究态、未经审校、不可生产激活。本规范只约束展示语言，不改变任何计算或状态原值。

> 以严密之数定其骨，以玄远之辞显其象，以明确之断落其意。

## 三层语言

普通阅读区只使用用户主语言；首次出现玄学词时给一句现代解释；工程原值只在“方法与版本”折叠区出现。

| 工程概念 | 用户主语言 | 首次解释 | 技术区原值 |
| --- | --- | --- | --- |
| Subject / Profile | 三际录／个人档案 | 本次记录与推演所归属的人 | 保留 ID |
| Create Subject | 立卷 | 建立一份如实、可撤回的个人档案 | create profile |
| Analysis Run | 起一卷／本次推演 | 按当前资料与指定版本执行一次 | execution ID |
| Replay | 复演 | 按当时输入和版本重放，不改变原卷 | replay manifest |
| Reanalysis | 重观 | 用当前版本另建一卷，不覆盖旧结果 | reanalysis parent |
| Compare | 两卷参照 | 说明输入、规则与版本造成的差异 | deterministic diff |
| Verdict | 断语 | 当前证契允许作出的主判断 | verdict |
| Evidence | 证契 | 支撑某一判断的独立资料 | evidence refs |
| Counterevidence | 逆证 | 与主判断相反或削弱它的资料 | counterevidence |
| Manifestation Period | 应期 | 规则支持的时间范围，不强造日期 | timing window |

| Confidence | 证契完备度 | 独立资料的完整、稳定与少冲突程度；不等同象势 | confidence_bp |

| Contested | 两象相争 | 两个主要候选接近或存在关键冲突 | contested |

## 正式页面名称

- 三际观、三际枢、三际录
- 六象合参、三际断章、宿世星图、中阴之门、命势长图、缘契图、观照录、历次命卷

“三际镜”仅允许出现在明确标注的历史资料中；不得出现在当前界面、导航、Metadata 或当前定位文案。

## 状态句式

- 成断：`象成，可断`，随后明确吉、凶、吉中藏险、凶中有转及主次。
- 相争：`两象相争`，并列双方证契、逆证和未能定主次的原因。
- 不足：`证契未足，不成断`，列出已有资料、尚缺资料与补充入口。
- 成文不可用：`成文服务暂未启用，三际枢的确定性结果仍然完整。`

不得用“也许如此，也可能不是”、虚假准确率、命中注定、AI 算前世或伪经典格式。象辞是本系统文字，不得冒充古籍、偈颂、师承或传统原句。普通身份不得被写成低级身份。

## 固定阅读顺序

三际断章依次展示：断语、象名、象辞、现代释义、应期、吉凶主次、证契、逆证、体系来源、方法与版本。技术字段不得进入第一屏。

规则引擎独占事实骨架、极性、象势、排序、状态、应期、证契和吉凶。DeepSeek 只可润色白名单文字；本轮不调用 DeepSeek。
