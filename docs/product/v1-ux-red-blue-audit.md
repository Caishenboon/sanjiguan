## 横向问题

### 术语冲突

`Strength/象势强度`、`Confidence/证据可信度`、`研究详情`、`Replay`、`Reanalysis`在普通页面混用。统一为象势、证契完备度、方法与版本、复演、重观。技术原值只留折叠区。

### 组件重复

结果状态曾由页面各自拼标题与分值；本轮收敛为 `VerdictBanner`、`MetricPair`、`PageState`、`TechnicalDetails`。研究管理员页面不强行迁移，以免扩大范围。

### 响应式

旧表格在手机容易横向滚动，报告技术区过早展开，固定按钮可能遮文。命势表格改移动卡片；主表单操作区保留安全底距；手机底栏固定五项。

### 无障碍

优点是已有语义表单、标签和视觉回归。缺口是缺少 Skip Link、统一焦点、图表文字等价、删除对话框焦点管理与 reduced-motion。以上均纳入本轮；删除对话框已覆盖初始焦点、循环、Escape 与返回触发点，后续只保留组件化技术债。

## 蓝队保留

- 五入口产品壳与现有品牌色、字体资产。
- 私人页面 noindex/no-store、PWA 私人缓存边界及真实 API 接线。
- PostgreSQL 权威三际录、RLS、复演与版本追溯。
- 已冻结的确定性报告结构和跨平台 Hash。
- CI 的 Linux/Windows 视觉基线、Lighthouse、安全与许可证门禁。
- 所有研究态、UNCONFIRMED 与不可生产激活边界。

## 延后项目

- 八字、紫微机械结果共用阅读器的完整统一。
- 登录/邀请页在真实会话下的独立可用性研究。
- 图谱交互的键盘漫游增强；当前以文本等价内容为可靠回退。
- 真正的 Toast 管理与通用对话框组件；当前状态使用 aria-live，并在删除对话框内完成焦点管理。
