# V1.2「诸象成仪」视觉系统

## 目标

“诸象成仪”把已有确定性结构投影为可阅读的研究仪器，使用户能够先看见主结构，再按需展开证据和版本。它是展示层，不是第二套算法。

## 八类仪器

| 能力 | 仪器 | 只允许投影的内容 |
| --- | --- | --- |
| 易经三钱 | 六爻演变仪 | 六爻阴阳、动爻、本卦和变卦 |
| 八字 | 四柱结构台 | 当前 Profile 返回的年、月、日、时柱 |
| 紫微 | 十二宫盘 | 已实现的命宫、身宫、五行局和宫位结构 |
| 六象 | 六象证据轮 | 六类资料覆盖、候选状态、支持与逆证 |
| 宿世 | 候选星图 | 带认识状态的候选及其排序 |
| 中阴 | 过渡之门 | 当前执行返回的过渡候选与资料状态 |
| 缘契 | 双主体关系结 | 单方/双方边界、候选和冲突状态 |
| 命势 | 命势计时仪 | 已授权事实数量、时间粒度和未来窗口状态 |

## 真实状态与动效

执行过程只使用真实请求状态，统一表达为“归卷—校核/成图—显现/成卷”。不展示伪造百分比，不用等待动画掩盖错误。返回结果后才显示对应仪器；资料不足继续使用结构化“不成断”状态。

动画遵守 `prefers-reduced-motion`。所有图形都有标题、图注或现有文字详情作为等价回退，状态不只依赖颜色。

## 工程边界

- `ObservationInstrument` 只接收 API 已返回或页面已持有的显示值。
- Web 不重算四柱、宫位、卦象、候选、分数、吉凶、应期或 Hash。
- 不修改 `sanji-engine`、Ruleset、Profile、Golden、migration 或受保护 Hash。
- 不新增远程字体、图表库、追踪脚本或第三方运行时依赖。
- 截图继续使用完全虚构的 `synthetic_conformance` 数据。

## 验收

桌面、平板、手机分别检查信息层级、文本回退、键盘阅读顺序和减少动态模式。受影响的 Snapshot 必须逐张审核后单独更新；禁止提高 Diff 容差或批量接受变化。

本地验收结果：

- Next.js production build：44 个路由构建成功；
- Playwright 桌面、平板与手机矩阵：57/57；
- 合成视觉证据：26/26，其中新增易经、八字、紫微三张仪器结果页；
- Python 全量回归：248 项通过，15 项按本地环境条件跳过；
- Storybook production build：通过；
- 产品语言、文档链接、发布静态门禁、便携性、Secret Scan：通过；
- 交接清单中的 17 个受保护 Hash：全部保持。

第一次并行视觉运行暴露“暂存退出后立即 reload”的测试竞态：导航快慢会决定 reload 发生在首页还是立卷页。测试改为等待退出落到首页，再显式进入立卷，未跳过测试或改变业务代码。第一次 Python 运行缺少项目 Node 路径，两个固定 iztro 对照返回外部执行错误；在标准运行环境复验后全套通过。两次失败均保留为本地诊断记录。
