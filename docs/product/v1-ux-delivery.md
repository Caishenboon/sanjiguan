# 三际观 V1 用户体验精修交付说明

## 页面与组件

- 首页：用户行动、研究边界与确定性成文说明白话化。
- 八步立卷：进度、隐私、未知值、暂存恢复、失败保留输入。
- 六象合参：主断置顶、六象卡片、象势与证契完备度分离。
- 三际断章：报告先于图表；确定性模板不是错误；技术字段折叠。
- 命势长图：非金融说明、历史/未来/留白图例、键盘标签、移动端文字卡片。
- 宿世星图、中阴之门、缘契图：正式命名、认识状态与同意边界。
- 三际录：复演、重观、两卷参照及不覆盖原卷说明。
- 设置：彻底销卷二次确认及复演影响提示。

## 响应式与无障碍

- 390px：五项底栏、单列表单、报告分章、命势阶段卡片。
- 768px：单列报告与可读命势图，表格不造成页面级横向滚动。
- 1440/1920px：稳定侧栏，结论与证据分层，报告最大阅读宽度受控。
- 提供 Skip Link、可见焦点、语义状态、aria-live、图表文字表、44px 操作目标、打印样式与 `prefers-reduced-motion`。

## 安全边界

不新增远程字体、追踪脚本或分析服务；不改变 noindex/no-store、PWA 私人缓存、RLS、权限、导出或 CSP。截图全部使用虚构资料。不调用 DeepSeek。

## 视觉证据

- 16 张审核截图覆盖 390、768、1440 与 1920 视口，以及首页、立卷、六象、三专题、命势断章、资料不足、两象相争、权限不足和删除确认。
- 截图属于 `synthetic_conformance`，不包含真实身份、出生、梦境、关系、凭据或 Provider 输出。
- 文件、路由、视口和 SHA-256 见 [`evidence/manifest.json`](evidence/manifest.json)，由 `scripts/validate_v1_ux_evidence.py` 校验。
- 首次采集发现专题断语受历史卡片网格影响而窄列换行，以及内部缺失字段名外露；修正后重新采集并逐页复核。

## 变更边界

- `ALGORITHM_RESULTS_CHANGED=false`
- `RULESETS_CHANGED=false`
- `PROTECTED_HASHES_CHANGED=false`
- `DEEPSEEK_CALLED=false`
- 未修改 Migration、OpenAPI 业务契约、Replay 语义、生产规则状态或权限模型。

## 保留技术债

1. 删除对话框已具备初始焦点、焦点循环、Escape 关闭与触发点恢复；后续仍可抽取为全站统一组件。
2. 八字、紫微机械页仍有部分研究术语，需在不改变机械契约前提下进入独立阅读器精修。
3. 宿世与缘契图当前以结构卡片和文本等价为主，未新增复杂可编辑图谱。
4. 平板侧栏仍为缩窄模式，后续可增加不改变五入口的信息抽屉。
