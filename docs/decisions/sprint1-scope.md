# Sprint 1 可执行范围与阻断范围

## 可立即执行（不依赖术数方法）

- 邀请、登录、服务端安全会话、角色和资源级授权骨架。
- profile/evidence CRUD、应用层 envelope encryption、RLS 与越权测试。
- 原始出生输入模型：法定时间、IANA zone ID、tzdb 版本、地点/经纬度来源、精度和用户确认状态。
- canonical JSON、输入哈希、method_id、ruleset version、审计事件和回放框架。
- Idempotency-Key 数据表和 400/409/422/重放语义。
- 删除 tombstone、活动数据删除编排、备份恢复过滤设计。
- 规则激活门禁、来源许可字段、知识分层 schema。
- DeepSeek Gateway 接口和假 provider；不得调用真实服务，不录入密钥。
