# 来源清单与可信等级

## 等级定义

- **A1**：权威机构官方标准、官方技术文档、馆藏影像/目录或可定位的一手经典。
- **A2**：正式传承机构、正式译经项目、出版社授权材料。
- **B1**：同行评审论文、学术百科、可靠学术专著。
- **B2**：可追溯版本的古籍转录或公共数字图书馆文本；须与影印本复核。
- **C**：从业者网站、百科或在线排盘；只能发现分歧，不作唯一金标准。
- **X**：来源不明、无版本、无许可或受传承限制；不得进入生产知识。
